How Resume Analysis Works
1
Text Parsing

Uses pdfplumber and python-docx to parse text and table content while checking magic bytes to reject corrupted files.

2
NLP & Skill Boundary Matching

Matches terms against canonical dictionary & aliases (e.g. "ReactJS" → "React", "Postgres" → "PostgreSQL", "C++", "Node.js").

3
Review & Profile Confirmation

Review detected skills, select proficiencies, and confirm. Persisted skills are tagged with source: resume.
